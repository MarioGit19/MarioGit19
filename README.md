## <img src="https://api.iconify.design/lucide/terminal.svg?color=%235CCB8F&height=26" align="top" />&nbsp; About me

I'm a **full stack developer** building websites, web apps and e-commerce products, from the
interface to the infrastructure. My focus right now is the **Shopify ecosystem**: I've spent the
past three years on it, on everything from small features and one-merchant customisations to
entire app architecture delivered on tight timelines, always following Shopify's standards and
best practices.

I care about pragmatic engineering and clean, maintainable code that solves real problems for
real people, and I'm equally at home in a React frontend, a Node backend or a Docker deployment.

**Open to new opportunities.**
